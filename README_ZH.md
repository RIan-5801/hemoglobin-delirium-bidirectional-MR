# 血红蛋白与谵妄双向孟德尔随机化：代码公开候选包

本目录是根据冻结分析代码和最终结果整理的GitHub正式上传版本`v1.0.0`。它不会替代或修改原始科研项目。

## 已完成

- 排除了3个原始GWAS、清洗数据、LD参考文件和PLINK二进制程序。
- 排除了论文写作、文献下载、旧失败版本及本地运行历史。
- 保留了各分析阶段最终采用的冻结脚本。
- 使用方向元数据修正后的最终结果矩阵。
- 独立核对了置信区间、主要P值、前向OR换算、异质性P值和SNP数量。
- 保留Chen前向MR-PRESSO在冻结配置下未完成的真实状态。
- 已纳入完整的`renv.lock`：记录R 4.6.1及89个R包，包括DBI 1.3.0、duckdb 1.5.5、renv 1.2.3、psych 2.6.5，以及固定到具体GitHub提交的TwoSampleMR和MR-PRESSO。

## 改为公开仓库前尚需完成

环境锁定和本机结果核验均已完成。将仓库改为公开前仍需：

1. 先以私有仓库上传并逐项检查，再改为公开；
2. 部分冻结脚本保留原始E盘路径，作为审计来源而未静默改写，因此本仓库不宣称可以一键重跑全部原始GWAS流程；
3. 公开后连接Zenodo并生成软件版本DOI。

本机核验于2026年8月21日通过，9项冻结结果检查均为`TRUE`。

详细信息见英文`README.md`和`docs/validation_report.md`。
